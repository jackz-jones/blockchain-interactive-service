# 踩坑记录

> 状态：生效 | 维护者：全员 | 最后更新：2026-11-23（sop.init 从 git log 提取）

## 范围

记录开发/部署/运行中遇到的非显然问题、AI 协作的失败案例、已知 Bug 的临时绕过方案。每条记录的目的不是"留念"，而是**逐步转化为规约要求**（更新 `coding-style.md` / `unittest/unittest.md` / `code-review.md` 等）。

## 写作规范

- 每条独立成节，标题用一句话描述现象
- 必备字段：日期、上下文、根因、临时绕过、根治方案、相关链接（PR/Issue）
- AI 失败案例必须保留：原始 Prompt、AI 输出、期望 vs 实际、根因分析
- 已沉淀为规约的条目标记 `✅ 已规约`，可定期归档

## 模板

```markdown

- **上下文**：{{何时何地、何种操作触发}}
```

## 记录

### 2026-07：AutoMigrate 报 Error 1091 Can't DROP uni_tenants_name

- **上下文**：dev 环境启动服务，`DatabaseConf.AutoMigrate` 开启时 MySQL 报错
- **根因**：GORM AutoMigrate 对已存在的唯一索引执行 DROP/重建，跨库（MySQL/PG/Kingbase）方言差异导致索引名不匹配
- **临时绕过**：dev 库手工处理索引
- **根治方案**：生产禁 AutoMigrate，以 `migrations/` SQL 为准（commit `e362798c`）
- **沉淀去向**：✅ 已规约：`sqls/database.md` §5 迁移
- **参考**：git `e362798c`

### 2026-06：注册新租户时 API Key 长度超限导致失败

- **上下文**：调用 `/api/v1/auth/register` 创建租户
- **根因**：生成的 API Key 超出 DB 列长度定义
- **临时绕过**：—
- **根治方案**：调整 Key 长度与列定义（commit `1ea23f94`）
- **沉淀去向**：待办：表结构变更走 migrations 双轨
- **参考**：git `1ea23f94`

### 2026-06：私钥脱敏值被提交导致 hex 解析失败

- **上下文**：脱敏后的私钥（前 4 后 4，中间 ****）被写回配置/日志再用于签名
- **根因**：Mask 产物被误当原值回流
- **临时绕过**：人工恢复原私钥
- **根治方案**：脱敏只发生在输出层（commit `98bffb6c`）
- **沉淀去向**：✅ 已规约：`AGENTS.md` 红线 3、`coding-style.md` 安全编码
- **参考**：git `98bffb6c`

### 2026-06：以太坊 WS 断连 / 私钥 0x 前缀兼容

- **上下文**：以太坊事件订阅长期运行中 WebSocket 掉线；部分租户私钥带 `0x` 前缀
- **根因**：WS 无自动降级重连；hex 解析不容忍 `0x`
- **临时绕过**：重启服务恢复订阅（断点在 Redis）
- **根治方案**：WS 连接降级处理 + 私钥 0x 前缀兼容（commit `bc6c7746`、`f9cd3bec`）
- **沉淀去向**：✅ 已规约：`relationship.md` 故障传播矩阵
- **参考**：git `bc6c7746`、`f9cd3bec`

### 2026-05：HTTP 请求取消导致写链失败

- **上下文**：客户端 HTTP 请求超时取消后，链上交易也随之中断
- **根因**：SDK 客户端透传了请求 ctx 到链调用
- **临时绕过**：—
- **根治方案**：SDK 客户端内部 context 一律用 `context.Background()` 派生（commit `deeb1e03`）
- **沉淀去向**：✅ 已规约：`AGENTS.md` 红线 5
- **参考**：git `deeb1e03`

### 2026-05：优雅退出后端口残留 / 退出顺序错误

- **上下文**：服务 shutdown 后端口仍被占用；再次启动失败
- **根因**：退出时先释放 SDK 资源再关 server，导致在途请求悬挂
- **临时绕过**：`lsof -i :8085` 后 kill
- **根治方案**：先关服务再释放 SDK 资源（commit `c2afd2c5`、`ae582c5f`）
- **沉淀去向**：待办：退出顺序纳入 code-review 检查项
- **参考**：git `c2afd2c5`、`ae582c5f`

### 2026-07：计费配额判定 / 原子计数 / 时区与半开区间错误

- **上下文**：billing 日/月用量统计与配额判定在时区切换、边界时间点出错
- **根因**：非原子计数器 + 时区处理 + 区间边界语义（闭/半开）不一致
- **根治方案**：原子计数、时区统一、半开区间（commit `266380d4`）
- **沉淀去向**：待办：billing 时间边界用例纳入 UT
- **参考**：git `266380d4`

### 2026-07：测试连接填错 URL/端口仍返回通过

- **上下文**：租户在控制台对链配置执行 test-connection
- **根因**：连接校验未真正验证目标可达性
- **根治方案**：补真实连通性校验（commit `fb0fc824`）
- **沉淀去向**：`glossary.md` VerifyConnection 词条
- **参考**：git `fb0fc824`

### 2026-07：架构文档 Mermaid 图渲染失败

- **上下文**：`doc/architecture_cn.md` 的 Mermaid 图无法渲染
- **根因**：subgraph ID 与节点 ID 命名冲突
- **根治方案**：重命名冲突 ID（commit `989dfae9`）
- **沉淀去向**：待办：文档 Mermaid ID 唯一性约定
- **参考**：git `989dfae9`
